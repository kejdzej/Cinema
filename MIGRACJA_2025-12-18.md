# Migracja bazy danych - 18.12.2025

## Co się zmieniło?

Dodaliśmy nowe funkcjonalności dla filmów:
- ✅ Strona z listą wszystkich filmów `/movies`
- ✅ Strona szczegółów filmu `/movie/:id` z trailerem YouTube
- ✅ Integracja z OMDb API (oceny IMDb, obsada, reżyser)
- ✅ Automatyczne tłumaczenie opisów z angielskiego na polski
- ✅ Nowe kolumny w tabeli `movies`

## Jak zaktualizować bazę danych po `git pull`?

### Opcja 1: Jeśli masz już dane w bazie (ZALECANE)

Uruchom plik migracji, który doda nowe kolumny i zaktualizuje istniejące filmy:

```bash
mysql -u root -p cinema < server/sql/add_movie_details.sql
```

### Opcja 2: Jeśli zakładasz bazę od zera

Usuń starą bazę i stwórz nową używając zaktualizowanych schematów:

```sql
DROP DATABASE IF EXISTS cinema;
CREATE DATABASE cinema;
USE cinema;
```

Potem zaimportuj wszystkie tabele z folderu `tabeli do bazy/`:

```bash
mysql -u root -p cinema < "tabeli do bazy/cinema_movies.sql"
mysql -u root -p cinema < "tabeli do bazy/cinema_users.sql"
# ... itd dla pozostałych tabel
```

## Nowe kolumny w tabeli `movies`:

| Kolumna | Typ | Opis |
|---------|-----|------|
| `trailer_url` | VARCHAR(255) | Link do trailera na YouTube |
| `genre` | VARCHAR(100) | Gatunek filmu (np. "Sci-Fi, Drama") |
| `director` | VARCHAR(200) | Reżyser filmu |
| `cast` | TEXT | Obsada (opcjonalne) |
| `imdb_id` | VARCHAR(20) | ID filmu w IMDb (np. "tt0816692") |
| `release_year` | INT | Rok premiery filmu |

## Konfiguracja OMDb API (WAŻNE!)

Aby działały oceny IMDb, musisz:

1. **Zdobyć darmowy klucz API:**
   - Wejdź na: http://www.omdbapi.com/apikey.aspx
   - Wybierz plan **FREE** (1000 zapytań/dzień)
   - Podaj email i aktywuj klucz

2. **Dodaj klucz do `.env`:**
   ```
   OMDB_API_KEY=twój_klucz_tutaj
   ```

3. **Restartuj serwer**

Bez klucza API nie będą działać:
- ❌ Oceny IMDb
- ❌ Pełny opis z IMDb
- ❌ Szczegółowe informacje o obsadzie

Ale będą działać:
- ✅ Trailery YouTube
- ✅ Podstawowe informacje z bazy danych
